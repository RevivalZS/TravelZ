# 🏞️ 旅游景点分享网站

一个简单美观的旅游景点介绍网站，适合与朋友分享旅行经历。

## ✨ 功能特点

- 🏞️ 景点展示页面 - 展示6个精选中国旅游景点
- 📍 地理位置标记 - 每个景点都有详细位置信息
- 📸 照片画廊 - 高清景点图片展示
- 🔍 智能筛选 - 按季节、类型、地区筛选景点
- 💬 分享功能 - 用户可以分享自己推荐的景点
- 📱 响应式设计 - 完美适配手机、平板、电脑
- 🎨 美观界面 - 现代化的设计，流畅的动画效果

## 🛠️ 技术栈

- HTML5 + CSS3
- JavaScript (Vanilla)
- 无需数据库（静态网站）
- GitHub Pages 部署

## 🚀 快速开始

1. 克隆仓库：`git clone https://github.com/RevivalZS/revival.git`
2. 打开 `index.html` 在浏览器中查看
3. 修改 `data/places.json` 添加你的景点
4. 网站已自动部署到GitHub Pages

## 📁 网站结构

```
revival/
```

## 📝 添加你的景点

编辑 `data/places.json` 文件：

```json
{
  "places": [
    {
      "id": 1,
      "name": "景点名称",
      "location": "地点",
      "description": "景点描述...",
      "image": "images/your-photo.jpg",
      "tags": ["自然", "历史", "美食"],
      "coordinates": {
        "lat": 31.2304,
        "lng": 121.4737
      }
    }
  ]
}
```
